About Zappy Mart

Zappy Mart is one small web store built several times over, so that a reader can open a working application for every stack the articles explain, read it end to end, and build it themselves.

This is the Angular store front. It is a single page application that calls the GraphQL API directly. It keeps the access token in memory only and refreshes it through a cookie the API sets, so a reload never leaves a token behind in the browser.

Every store front in the family serves the same six screens from the same contract: the catalogue, one product, the cart, the checkout, the order confirmation, and the account with the order history and the sessions.
